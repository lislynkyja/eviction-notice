Bug reports and ideas for [Eviction Notice](https://modrinth.com/mod/eviction-notice), the Fabric mod that keeps villagers out of your house or base.

This repo is only for issues. The mod itself is on [Modrinth](https://modrinth.com/mod/eviction-notice).

## Found a bug?

[Open a bug report](../../issues/new?template=1_bug_report.yml). Please include your versions, your mod list and `logs/latest.log`, that makes it a lot easier to find the problem.

## Crashed?

[Open a crash report](../../issues/new?template=2_crash_report.yml) with the crash report from `crash-reports/`.

## Got an idea?

[Suggest a feature](../../issues/new?template=3_feature_request.yml). Already planned: limits and admin commands for servers, and a way to see the zone outline in game.

## Anything else?

[Ask a question](../../issues/new?template=4_question.yml), or use [something else](../../issues/new?template=5_other.yml) if nothing above fits.
